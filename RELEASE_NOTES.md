# PDF RAG Assistant v1.0.0

This is the first public portfolio release of PDF RAG Assistant.

## Highlights

- Ask questions across text-based and scanned PDF documents
- Local PDF extraction, OCR, embeddings, and Qdrant retrieval
- Gemini receives only the question and selected source passages
- Page-level source metadata and similarity scores
- FastAPI backend, Streamlit UI, tests, CI, Docker, and Windows scripts

## Scope

The release is designed for local learning, demonstration, and portfolio use. It is not presented as a production-ready document-security platform. Known limitations and the planned improvements are listed in the README.
