# Changelog

## 1.0.0 — 2026-07-29

Initial public portfolio release.

### Added

- Multi-PDF ingestion and persistent local indexing
- Page-aware text extraction with PyMuPDF
- Automatic Tesseract OCR fallback for scanned pages
- Turkish and English OCR support
- Local multilingual embeddings with Sentence Transformers
- Qdrant Local semantic retrieval
- Gemini-based source-grounded answer generation
- Source filename, page, chunk, score, and passage display
- FastAPI API and Streamlit interface
- Health-aware launcher and Windows setup scripts
- Docker and Docker Compose files
- Unit tests, Ruff, GitHub Actions, and Dependabot
- Security, privacy, contribution, and troubleshooting documentation
